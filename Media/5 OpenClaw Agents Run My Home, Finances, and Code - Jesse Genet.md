# 5 OpenClaw Agents Run My Home, Finances, and Code — Jesse Genet

> Jesse Genet is a homeschooling parent and entrepreneur who runs her household with five specialised OpenClaw agents, each with its own role, persona, and dedicated Mac Mini, all layered on top of her Obsidian second brain.

<iframe width="560" height="315" src="https://www.youtube.com/embed/96Vl8s3EQhk" frameborder="0" allowfullscreen></iframe>

---

## Background

Jesse discovered OpenClaw (originally called Cloudbot/Quadbot) through an Obsidian community comment. She'd been using Obsidian to organise her homeschool — her vault is called **Family Learning** — but didn't have enough time to maintain it properly with four young kids. OpenClaw became the answer: an AI agent that does the heavy lifting inside her own files.

She frames her life in two phases: **before Claw** and **after Claw**.

---

## The Setup: Five Agents, Five Mac Minis

Jesse runs five specialised OpenClaw agents, each scoped to a distinct role and deployed on its own Mac Mini:

| Agent | Role |
|-------|------|
| **Homeschool** | Logs lessons, plans curriculum, tracks each child's progress |
| **Finance** | Manages budgets, syncs with QuickBooks |
| **Scheduling** | Coordinates calendar and household logistics |
| **Development** | Builds and ships software (no terminal experience required) |
| **Operations** | General household ops, printing, inventory |

Each agent has its own **SOUL.md file** — a persona and personality document that defines its scope, tone, and responsibilities. Jesse treats agent onboarding like employee onboarding.

---

## Key Workflows

### Homeschool Logging & Curriculum Planning
- After a lesson, Jesse photographs what they did and uploads the images
- The homeschool agent logs the full lesson contents into Obsidian with structured data: date, instructor, which children were involved, what was taught, notes, and what might come next
- The AI tracks each child's progression over time and suggests next lessons based on what's already been covered
- Also photographs entire curriculum books page-by-page to have the agent generate formatted, ready-to-teach lesson plans

### Building a Custom Kids' TV App (with zero terminal experience)
- Jesse wanted a curated, "slop-free" alternative to YouTube Kids for her children
- Used her development agent to build a custom kids' TV app from scratch
- Shipped it to a real television in **four days**
- No prior experience with the terminal

### Physical Inventory
- Photographed every toy, book, and supply cupboard in the house
- The agent created a searchable inventory of all physical items
- The homeschool agent can now recommend real, specific materials already in the house when planning lessons

### Hands-Free Printing
- Old workflow: scan → upload → email → print (multiple manual steps)
- New workflow: "Sylvie, print this" — done in ~30 seconds
- Reduced a recurring friction point to a single voice command

### Decision Files & Agent Memory
- Jesse uses **decision files** — documents where agents record choices made and reasoning
- Helps maintain consistency across sessions and prevents agents from re-litigating settled decisions
- Alongside SOUL.md, these are her primary tools for managing long-running agent behaviour

---

## Multi-Agent Collaboration

Jesse runs agents that hand off to each other, but notes this is still a weak point in the current ecosystem — no messaging platform handles agent-to-agent handoffs cleanly. The agents collaborate, but the coordination layer is still manual in places.

---

## Key Takeaways

- **Specialised agents outperform generalist ones** — giving each agent a clear scope and persona makes them more reliable and easier to manage
- **Obsidian as an agent substrate** — local markdown files give agents persistent, structured context to read and write into
- **Personal software lowers the floor for non-technical builders** — Jesse shipped a TV app with no terminal experience
- **Physical world + AI** — photographing the real world (lessons, books, cupboards) is an underused way to feed agents rich context
- **Agent onboarding matters** — SOUL.md and decision files are the equivalent of an employee handbook
