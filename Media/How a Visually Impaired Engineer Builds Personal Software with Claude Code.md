# How a Visually Impaired Engineer Builds Personal Software with Claude Code

> Joe McCormick, a principal software engineer at Babylist, demonstrates how he uses Claude Code to build micro Chrome extensions that make his everyday work and life more accessible — and why personal software is one of AI's most underappreciated benefits.

## Background

Joe lost most of his central vision before starting college due to **Leber's hereditary optic neuropathy**, a rare genetic disorder. He pivoted from mechanical engineering to computer science at Harvard, finding that software gave him the same creative satisfaction without the physical limitations. He now leads AI enablement at Babylist, helping engineers build with AI across the full software development lifecycle.

AI has been transformative for him both professionally and personally — closing the gap between what a sighted engineer and a visually impaired engineer can do, day by day.

---

## The Case for Personal Software

Accessibility software is often not an economically viable business to build at scale — there's limited incentive to create fully robust tools for every individual's needs. AI changes this. People can now build customised solutions for themselves in under an hour, tailored to their specific experience and workflow rather than relying on what the market happens to produce.

Joe's preference for focused Chrome extensions over AI-native browsers: purpose-built tools are faster and more precise — "use the drill, not the Swiss Army knife."

---

## Extensions Demoed

### 1. Image Description for Slack
- **Shortcut:** `Ctrl+Shift+D` on any Slack message
- Sends the image to ChatGPT and returns a description inline
- Supports follow-up questions (e.g. "What age child is this for?")
- Built in ~25 minutes with Claude Code
- A Figma version is in progress — describes node colours, layout, and design intent via a keyboard shortcut

### 2. AI Spell Checker
- Addresses typos caused by his brain moving faster than his fingers
- Runs on any website via keyboard shortcut
- Faster and more targeted than browser-native spell check

### 3. Link Summariser (built live during the episode)
- Built from scratch during the recording using Claude Code
- Summarises URLs shared in Slack without having to open them
- Used **Claude Skills** to extract repeating patterns from previous extensions and apply them to the new one — significantly reducing boilerplate setup

---

## Workflow Insights

- **Keyboard shortcuts are essential** — reducing mouse dependency directly reduces cognitive and physical friction for visually impaired users
- **Claude Skills** let you codify patterns from previous projects and reuse them, accelerating development of similar tools
- **Developer mode in Chrome** makes it easy to load and test unpacked extensions during development
- Getting fluent with AI tools means understanding when to trust the output and when to review the plan before generating code

---

## Key Takeaways

- Personal software is increasingly viable — AI removes the economic barrier to building niche, customised tools
- Accessibility needs that mainstream products overlook can now be self-served
- Multimodal AI (image description, voice, smart glasses) is compounding the accessibility gains beyond just coding
- The gap between what a sighted and visually impaired engineer can build is closing rapidly

## Notable Quotes

> "This is one of those things where I tell people to work on their **anti-to-do list**. When you have a recurring task or a recurring point of friction... it's 100% worth it instead of spending the time on the task itself to spend the time **never having to do that task again**.
>
> The payback period of personal software is basically collapsing to zero... it is much more important to learn to build some of these tools than to do the task right now. The payoff is so much higher to learn how to automate the task versus doing the task.
>
> If you can just change your muscle memory to — every time you do the task, pause yourself and say, 'Actually, I'm going to learn how to automate the task' — you can really create a lot of leverage in your day-to-day life, even in your personal life."

— **Claire Vo** ([33:36](https://youtu.be/sibufEEhH6A?t=2016))
