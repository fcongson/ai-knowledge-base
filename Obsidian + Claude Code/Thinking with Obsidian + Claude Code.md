# Thinking with Obsidian + Claude Code

> A lightweight guide to building your own AI-powered second brain

## What this is

This is not a rigid system or framework.

It's a starting point to help you:

- capture what you're working on
- make sense of it with AI
- gradually build a system that works for you

There is no "correct" setup. The goal is to **start simple and evolve over time**.

---

## 1. The core idea

**Obsidian = where your thinking lives**
- notes
- ideas
- meeting takeaways
- decisions
- drafts

**Claude Code = your thinking partner**
- helps clean up messy notes
- summarizes and connects ideas
- turns rough thoughts into something useful

A simple rule:
> **Capture in Obsidian → Refine with Claude**

---

## 2. Set up in under 5 minutes

1. Install Obsidian
2. Create a new vault
   - Give it any name (e.g. "Notes", "Work", "Brain")
3. Create one note and start writing

That's it.

Avoid setting up folders, tags, or systems upfront unless you feel you need them.

---

## 3. Start capturing real work immediately

Don't wait to "design your system."

Just start writing things like:
- meeting notes
- project thoughts
- ideas
- things you don't want to forget
- decisions you made
- questions you have

**Example:**

```markdown
# Search improvements discussion

We talked about improving search relevance.

- main issue is ranking
- users struggle with filters
- might need better defaults

Decision:
Test new ranking logic first

Next steps:
- prototype ranking changes
- review with team next week
```

Messy is fine. In fact, messy is expected.

---

## 4. Use Claude Code to make your notes useful

This is where the system becomes powerful.

Take any rough note and ask:
- "Clean this up into a structured note"
- "Summarize this into key points and decisions"
- "What are the next steps from this?"
- "Turn this into something reusable for the team"

You don't need to write perfectly — Claude helps you refine later.

---

## 5. Let your structure emerge naturally

After a few days or weeks, you'll start noticing patterns:
- certain types of notes repeat (e.g. meetings, ideas, plans)
- you look for things in similar ways
- some notes feel more important than others

Only then, if it feels helpful:
- create folders
- create templates
- group related notes
- rename things

Build structure in **response to friction**, not in anticipation of it.

---

## 6. Connect ideas as you go

When you notice two things are related, link them.

**Example:**
```markdown
Related:
- [[Search improvements discussion]]
- [[Ranking experiments]]
```

You don't need a grand system—just connect things when it feels useful.

Over time, this becomes your "second brain."

---

## 7. A simple working rhythm

No strict rules—just a light rhythm:

**During work**
- jot things down quickly
- don't worry about format

**Occasionally (end of day or week)**
- ask Claude to clean things up
- clarify decisions and next steps

**Over time**
- organize only what feels messy or hard to find
- improve notes that are worth keeping

---

## 8. What to avoid early on

- overthinking folder structures
- creating too many rules
- trying to make everything perfect
- copying someone else's system exactly

If it feels like overhead, it probably is.

---

## 9. What good looks like

After a few weeks, you should:
- have a habit of capturing thoughts
- be able to clean up notes quickly with AI
- find things more easily than before
- start seeing connections between ideas

Not perfect. Just useful.

---

## 10. One principle to remember

> Your system should adapt to you—not the other way around.

If something feels unnecessary, remove it.
If something feels missing, add it.

That's how a real second brain develops.
